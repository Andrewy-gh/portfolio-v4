# Andy Yu

Andy Yu is a full stack software engineer who builds reliable, accessible web applications across frontend and backend systems. His primary tools include TypeScript, React, Node.js, Go, PostgreSQL, and modern testing and deployment tooling.

Canonical portfolio: https://andrewy.me/

## Recent work

### Fittrack

A full-stack fitness tracking application with a React and TypeScript interface, TanStack Router, Query, and Form, a Go API documented with OpenAPI, PostgreSQL through Supabase, Stack Auth, Docker, and GitHub Actions.

- Live site: https://fittrack.fly.dev/
- Source: https://github.com/Andrewy-gh/fittrack

### Anica Buckson

A portfolio for an NYC-based fashion stylist whose work has appeared in Harper's Bazaar and Vogue, including collaborations with Levi's, New Balance, and IKEA.

- Live site: https://www.anicabuckson.com/

### Cut Above Barbershop

An appointment platform supporting customer booking, rescheduling, cancellations, staff availability, administration, and retryable customer email notifications. Built with React, TypeScript, Convex, and Better Auth.

- Live site: https://cut-above.vercel.app/
- Source: https://github.com/Andrewy-gh/cut-above-barbershop

### Takashi Photography

A photography portfolio and publishing system with Cloudinary-optimized galleries and a protected administration dashboard for uploads, categories, and image ordering. Built with React, Hono, PostgreSQL, Drizzle, Supabase, and Cloudinary.

- Live site: https://takashi-photo.vercel.app/
- Source: https://github.com/Andrewy-gh/takashi-portfolio-full-stack

### Spruce Street

A responsive website for a local plant store, built with React, TypeScript, Tailwind CSS, and Vite.

- Live site: https://spruce-street.netlify.app/
- Source: https://github.com/Andrewy-gh/spruce-street
